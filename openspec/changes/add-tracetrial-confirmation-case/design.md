## Risks / Trade-offs

- Literal-command recognizers can miss correct shell-variable loops, absolute paths or Python wrappers → retain official scores and separately attribute observed grader coverage; no Actor hints or rescoring this trial.
- Official exit/state checks do not fully bind expected success to actual state → independently inspect native 0/75 and completed/failed rather than relying solely on points.
- A single long shell loop can encounter existing Bash 30-second/default-output limits → retain as measured behavior, do not pre-change tools.
- Longer task budget can increase model cost → explicit transport/output/request/time guards, one trial, no automatic rerun, usage retained; $5 reference is not billing enforcement.
- Process sampling is a bounded observation and zombies are separate from live residuals → retain the unchanged scope/schema and do not generalize beyond the actual receipt.
